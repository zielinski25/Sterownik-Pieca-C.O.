FIRMWARE 3.58.3 - co zrobic w 3 krokach
=======================================
(poprawka po trzecim tescie: zgodnie z Twoja decyzja "kto podlaczy sie do
 sieci, ten moze sterowac" - w trybie lokalnym token komend pobiera sie
 AUTOMATYCZNIE z centrali; niczego nie wpisujesz, dziala tez w incognito;
 szczegoly w README.md)
Zmienia sie JEDEN plik: src/main_centrala.cpp
Plikow .h NIE ruszaj. NIE nadpisuj src\secrets.h (tam sa Twoje hasla).
Biblioteki i platformio.ini: BEZ ZMIAN (identyczne jak przy 3.57.9).


CO DAJE TA WERSJA
-----------------
1) Nowy panel (http://<IP>/) dziala w sieci lokalnej BEZ Firebase:
   - stan z GET /api/lan/status (ten sam JSON co /piec/status),
   - komendy przez POST /api/lan/cmd + potwierdzenie GET /api/lan/ack,
   - zero logowania do ODCZYTU danych.
   Wykrywanie jest automatyczne: panel otwarty z centrali = tryb lokalny,
   panel otwarty z pliku/innej domeny = Firebase jak dotychczas.
   OD 3.58.1: sonda ma 3 proby i samonaprawia sie (powrot do aplikacji,
   odzyskanie sieci, klik "STARA WERSJA") - chwilowy brak odpowiedzi
   centrali NIE blokuje juz trybu lokalnego na cala sesje.

2) Przelacznik stron: stara strona wraca pod adresem /stara
   (przycisk "STARA WERSJA" w pasku pulpitu + karta "Starsza strona
   lokalna" w Ustawieniach - OBA zawsze widoczne; ze starej strony
   przycisk "NOWY PANEL" w pasku na gorze). Panel otwarty ZDALNIE
   (przez Firebase) po kliknieciu pokaze wskazowke, jak otworzyc panel
   z adresu centrali - nie przejdzie na /stara.

   DIAGNOSTYKA (nowe w 3.58.1): Ustawienia -> Sesja operatora pokazuje
   WERSJE CENTRALI (pole fw) i ZRODLO DANYCH (lokalne API /api/lan/status
   czy Firebase RTDB). Jezeli widzisz "Firebase RTDB (lokalne API nie
   odpowiedzialo)" a otworzyles panel z adresu centrali - kliknij
   "STARA WERSJA" (ponawia sonde) albo odswiez strone.

3) TOKEN KOMEND (NOWE w 3.58.3 - zgodnie z Twoja decyzja):
   model dostepu = "kto podlaczy sie do sieci, ten moze sterowac"
   (dokladnie jak w starej stronie - jej endpointy od lat nie wymagaja
   tokena). W trybie lokalnym (panel otwarty z IP centrali):
   - token komend POBIERA SIE AUTOMATYCZNIE z centrali (GET /api/lan/token),
     panel zapamietuje go w przegladarce - NICZEGO NIE WPISUJESZ,
     rowniez w nowej przegladarce / incognito,
   - jesli zmienisz SECRET_CMD_TOKEN w secrets.h i wgriesz nowy firmware,
     panel sam odkryje rozjazdz: 403 -> odswiezy token -> ponowi komende,
   - awaryjnie (np. stary firmware bez tego endpointu): okno polaczenia
     ma pole "Token komend" i przycisk "ZAPISZ TOKEN (TRYB LOKALNY)"
     (z v3.58.2) - wpisujesz wartosc SECRET_CMD_TOKEN ze swojego secrets.h.
   Praca ZDALNA (panel z plika/innej domeny, przez Firebase) bez zmian:
   tam token nadal wpisujesz recznie (raz, w danych polaczenia).
   /api/lan/cmd nadal pelnie weryfikuje token (aplikacja Android bez zmian).
   Odczyt danych dziala bez tokenu.

KROK 3 - TEST NA GOLEJ PLYTCE (zanim podejdziesz do pieca)
----------------------------------------------------------
1. Wgraj firmware, otworz serial (115200) i zanotuj IP.
2. W przegladarce: http://<IP>/
   - bez internetu w sieci: panel ma pokazac "LIVE", temperature itd.
     (dane z /api/lan/status), banner polaczenia ukryty.
3. Przelacznik stron: przycisk "STARA WERSJA" w pasku pulpitu (albo
   Ustawienia -> "Starsza strona lokalna") -> otwiera /stara;
   ze starej strony przycisk "NOWY PANEL" wroci do /.
   Ustawienia -> "Sesja operatora": sprawdz "Wersja centrali: v3.58.3"
   (jesli widzisz v3.58.2 lub starsza - przegladarka/cache ma stara strone,
   odswiez Ctrl+F5) oraz "Zrodlo danych" (lokalne API czy Firebase).
4. Komenda/symulacja - SCENARIUSZ INCOGNITO (najlepszy test v3.58.3):
   - otworz panel w nowej karcie incognito (pusta pamiec przegladarki),
   - sprobuj komendy/symulacji (np. symulacja temperatury pokoju):
     MA DZIALAC OD RAZU - token pobiera sie sam, zadne okno sie nie otwiera,
     toast: "Potwierdzone przez sterownik (ACK, ...ms)".
   Jezeli jednak pojawi sie 403 i okno polaczenia (awaria autopobrania):
   wpisz wartosc SECRET_CMD_TOKEN ze swojego secrets.h i kliknij
   "ZAPISZ TOKEN (TRYB LOKALNY)", ponow komende.
5. Wylacz centrale (zasilanie) - banner "Brak polaczenia ze sterownikiem
   w sieci lokalnej"; wlacz - banner znika, dane wracaja.

UWAGA (zgodnie z Twoja uwaga z instrukcji): sama gola plytka NIE gwarantuje
odlaczenia od prawdziwej bazy - moze miec zapisane dane sieci i Firebase.
Ta wersja NIE wysyla nic do Firebase z samego panelu otwartego z centrali,
ale centrala (firmware) laczy sie z Firebase tak samo jak 3.57.9, jesli ma
dane sieciowe i internet.
